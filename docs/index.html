The Backend Engineering Handbook

How backend systems really work, from your first line of code to principal engineer: 98 Parts in plain language, with diagrams, real code and production stories.

For beginners, working backend and full-stack developers, senior engineers and architects. Free to read in your browser.

    Five stages from beginner to staff engineer, each with its reading order, what to build and how to know you are ready.

    1. Stage 1Beginner foundationThree to six months
    2. Stage 2Backend engineerNine to eighteen months
    3. Stage 3Advanced backend engineerTwelve to twenty-four months
    4. Stage 4Senior backend engineerTwo to four years from Stage 3
