From Part 69: The Knowledge Map and Learning Roadmap

The learning roadmap

Five stages from beginner to staff engineer. Each stage has a goal, a reading order and a realistic time for someone who studies alongside a full-time job. Choose a path to see which stages it covers.

Highlight a path
  1. 1

    Three to six months

    Stage 1 Beginner foundation

    Understand what happens underneath before you learn any framework's opinion about it.

    15 Parts, in order
    1. 0How to Understand Any Technology
    2. 1Programming Fundamentals in JavaScript and TypeScript
    3. 2Asynchronous JavaScript
    4. 3How the Web Works
    5. 4Linux and the Command Line
    6. 5Git Basics and the Development Workflow
    7. 6Your First Backend
    8. 7Your First Frontend
    9. 52Git from Intermediate to Senior
    10. 10Computer Science Fundamentals: Data Structures
    11. 11Algorithms for Backend Engineers
    12. 13Operating Systems and the Node.js Runtime
    13. 14Networking and HTTP
    14. 20Databases and the Relational Model
    15. 21SQL Mastery for Backend Engineers

    Ready for the next stage when: You can explain to another person, without notes, what happens between a browser request and a database row being returned, including where the time goes.

    Full stage in Part 69 (build alongside, skills, exit test)

  2. 2

    Nine to eighteen months

    Stage 2 Backend engineer

    Build and ship a complete, correct API on your own: modelled, validated, tested, containerised, deployed, and not embarrassing.

    13 Parts, in order

    12. 57AI-Assisted Engineering
    13. 87Frontend and Full-Stack Interview Preparation

    Ready for the next stage when: You have shipped something to real users, and when it broke you fixed it yourself using logs and metrics rather than by guessing.

    Full stage in Part 69 (build alongside, skills, exit test)
